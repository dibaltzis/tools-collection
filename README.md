# tools

A collection of small, practical tools for self-hosting and infrastructure.

---

## Available tools

- [proxy-gen](./tools/proxy-gen/) – generate nginx + Authelia configs from a single file  
- [debian-golden-image-builder](./tools/debian-golden-image-builder/) – create and clone Debian VMs with libvirt  
- [docker-multiarch-build](./tools/docker-multiarch-build/) – build and push multi-arch Docker images  
- [jenkins-agent-custom-ca](./tools/jenkins-agent-custom-ca/) – Jenkins agent with Docker and custom CA support
- [kubeadm-libvirt-cluster](./tools/kubeadm-libvirt-cluster/) – provision a local multi-node Kubernetes cluster with Terraform, libvirt, and Ansible
