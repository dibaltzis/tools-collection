# tools

A collection of small, practical tools for self-hosting and infrastructure.

---

## Available tools

- [proxy-gen](./proxy-gen/) – generate nginx + Authelia configs from a single file  
- [debian-golden-image-builder](./debian-golden-image-builder/) – create and clone Debian VMs with libvirt  
- [docker-multiarch-build](./docker-multiarch-build/) – build and push multi-arch Docker images  
- [jenkins-agent-custom-ca](./jenkins-agent-custom-ca/) – Jenkins agent with Docker and custom CA support
